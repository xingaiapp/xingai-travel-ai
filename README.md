# XingAI Travel AI

**Explore Better** — AI-powered travel planning and destination recommendations.

Part of [XingAI](https://xingai.app) — AI Decision Systems for Everyday Life.

## About

XingAI Travel AI helps users plan trips, discover destinations, and make smarter travel decisions with personalized itineraries, budget optimization, and local recommendations.

## Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Backend:** FastAPI, Python
- **AI:** OpenAI API
- **Deployment:** Vercel

## Getting Started

```bash
npm install
npm run dev
```
